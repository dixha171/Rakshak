Scans your code and suggests fixes — nothing is compiled or run. Covers software (C, Python, JavaScript) and hardware (Verilog, VHDL); hardware fixes always need human review.

Fuzz a Benchmark Target

Runs mutated inputs against a compiled target looking for crashes nobody's written a test for yet. Any crash found goes through the same triage → patch → review → verify pipeline as everything else.
